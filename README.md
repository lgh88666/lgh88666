我正在从零构建 **[Dragon Code](https://github.com/lgh88666/Dragon-Code)**，一个运行在终端中的 AI 编程助手。

它可以理解项目、调用工具、修改代码、运行验证，并将复杂任务交给独立的子 Agent 处理。我关注的不只是让模型回答问题，也在探索如何让 Agent 更安全、可靠地参与真实开发流程。

## Dragon Code

- ⚡ **自主执行**：ReAct Agent Loop，支持文件读写、Shell、搜索等工具
- 🛡️ **安全边界**：权限规则、路径沙箱和人在回路
- 🧠 **上下文与记忆**：上下文压缩、会话恢复、项目指令和长期记忆
- 🔌 **可扩展能力**：MCP、Skill 与 Hook
- 🧩 **任务协作**：SubAgent、后台任务与 Git Worktree 隔离
- 🎛️ **终端体验**：基于 Textual 的交互界面

**Python 3.12 · Textual · MCP · Agent**
